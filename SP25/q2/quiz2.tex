		\begin{enumerate}
			\item A first order ODE is written as
				$P(x,y)dx+Q(x,y)dy=0$. Write down the condition
				for the ODE to be exact.
			\item Consider the ODE $(e^xy^2+\sin y)dx+(2e^xy+x\cos
				y)dy=0$. Determine wether it is exact, show
				your work.
			\item For the ODE in part (ii), if it is exact, find the general solution.
		\end{enumerate}
	\item (10 points) Problem 2. Consider the population model
		$y'(t)=\frac{y}{10}\left(1-\frac{y}{K}\right)$ with capacity $K>0$.
		\begin{enumerate}
			\item Find the general solution of the ODE.
			\item Assume the initial population is one-third of the
				capacity. Find the time at which the population
				has doubled.
			\item Sketch the solution in Part (ii) on the $ty$-plane. Find the limit $\lim_{t\to\infty}y(t)$.
		\end{enumerate}
